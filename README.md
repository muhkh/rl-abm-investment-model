# RL-ABM Investment Model

Research code and NetLogo model integrating **Proximal Policy Optimization (PPO)** with **Agent-Based Modeling (ABM)** for dynamic investment decision-making.

The published model is also available through the **CoMSES Computational Model Library**:

https://doi.org/10.25937/644j-cv09

## How to Cite

If you use this model in academic work, please cite the archived CoMSES release:

Ali, M. K., Ali, H., & Mohammad, H. (2026). *Integrating Reinforcement Learning in Agent-Based Modeling for Dynamic Investment Decisions* (Version 1.0.0). CoMSES Computational Model Library. https://doi.org/10.25937/644j-cv09
